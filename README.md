# 💅 Caso de Estudio: Plataforma Web para Salón de Belleza y Estética

Prototipo funcional y caso de estudio interactivo desarrollado para la digitalización de servicios en el sector de la belleza y estética personal.

## 🔗 Demo Interactiva en Vivo
👉 **https://estetica-maite-demo.vercel.app/**

---

## 🎯 Objetivos del Proyecto
* **Estructura visual clara:** Presentación limpia de la carta de servicios, tratamientos faciales/corporales y precios actualizados.
* **Captación de citas:** Diseño enfocado a la conversión rápida y facilidades de contacto directo para reservas.
* **Diseño adaptativo (Responsive):** Totalmente optimizado para una navegación ágil en dispositivos móviles.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **AI Studio:** Desarrollo visual y estructuración del prototipo.
* **Ingeniería de Prompts & IA:** Generación y optimización de layout y componentes.
* **UI/UX Design:** Paleta de colores suave, tipografías legibles y arquitectura de la información orientada a negocios de estética.
